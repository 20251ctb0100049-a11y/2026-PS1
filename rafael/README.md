# SysControl v2.0 - Gestão de Chamados

## 📌 Variante
- **Matrícula final:** 9
- **Entidade:** Chamado (implementada como classe `produto`)
- **Dados personalizados:** Dia 7 e iniciais "RA"

## 🛠️ Regras e Validações Implementadas
1. **Número do chamado:** Deve ser positivo (> 0).
2. **Descrição:** Não pode ser nula nem vazia.
3. **Prioridade:** Aceita apenas "BAIXA", "MEDIA" ou "ALTA".

## 🧩 Desafios Complementares Escolhidos
1. Atributo adicional: `tecnicoResponsavel`.
2. Método de resumo textual: `gerarResumo()`.
